# ⛪ ZeoGrace (Python / PyQt6 Edition)

**ZeoGrace** — це настільний сучасний застосунок для обліку, впорядкування та ведення бази даних членів громади, аналізу родинних зв'язків і формування друкованих PDF-звітів.

## 🚀 Основні можливості

### 👤 Облік громади
* **Повна картка особи:** П.І.Б., адреса, мобільні (основний та додатковий), домашній та робочий телефони, email, дати народження та хрещення, стать, сімейний стан, статус у церкві, кількість дітей, примітки.
* **Збереження фотографій:** завантаження, масштабування зі збереженням пропорцій, експорт та видалення фото.
* **Гнучке керування датами:** можливість очищення або залишення незаповненими дат народження/хрещення.

![Картка особи](<screenshots/Знімок екрана 2026-10-14 105925.png>) ![Картка особи](<screenshots/Знімок екрана 2026-10-14 110000.png>)

### 👨‍👩‍👧‍👦 Аналіз та встановлення родинних зв'язків
* **Автоматичне виявлення шлюбів:** інтелектуальний аналіз подій та прізвищ для формування шлюбних пар.
* **Автоматичний пошук дітей:** сканування подій і записів бази з виявленням кандидатів на створення нових карток чи прив'язку до батьків.
* **Розширений аналіз родства:** виявлення дідусів/бабусь, братів/сестер, дядьків/тіток, двоюрідних родичів за графом зв'язків.
* **Діалоги підтвердження:** пакетне застосування знайдених зв'язків із можливістю точкового вибору прапорцями.
* **Вікно «Родини та сім'ї»:** групування громади за нуклеарними сім'ями, прямими лініями або повними родинами з виводом у вигляді дерева.

### 🔍 Фільтрація, пошук та довідники
* **Швидкий пошук:** за іменем, адресою або номером телефону у реальному часі.
* **Фільтр ДН:** вибір осіб, у яких День народження на поточному тижні.
* **Розширений фільтр:** комбінована фільтрація за церковним статусом, статтю, сімейним станом, ролями у групах, типами подій та діапазоном дат.
* **Редактор довідників:** зручне редагування класифікаторів (статуси, типи подій, ролі в групах, типи зв'язків).

![Картка особи](<screenshots/Знімок екрана 2026-10-14 110116>)


### 📄 Експорт у PDF
* **Інтерактивний попередній перегляд:** динамічний рендеринг першої сторінки при виборі налаштувань.
* **Різноманітні макети:**
  * **А4 Картки:** по 2 картки в рядку з фотографіями.
  * **Для телефону (A5):** компактні плитки, оптимізовані під перегляд на мобільних пристроях.
  * **Компактна таблиця:** табличний вивід без фото для економії місця.
  * **PDF-звіт родин:** друк згрупованих сімейних структур.
* **Стилізація:** підтримка 5 колірних схем (Slate, Modern Blue, Warm Amber, Emerald, Minimal).
* **Динамічна нумерація:** автоматичне формування сторінок формату «Сторінка X з Y».

![Картка особи](<screenshots/Знімок екрана 2026-10-14 110228.png>)


### 🛡️ Надійність та безпека даних
* **Автоматичне резервне копіювання:** періодичний бэкап за таймером у фоновому режимі.
* **Бэкап перед пакетними операціями:** автоматичне збереження стану бази перед масовим додаванням зв'язків.
* **Ротація бэкапів:** автоматичне видалення найстаріших копій при досягненні встановленого ліміту.

## 🛠️ Технологічний стек

* **Мова програмування:** Python 3.10+
* **GUI Фреймворк:** PyQt6
* **База даних:** SQLite3 (з підтримкою україномовної сортувальної локалі `UKRAINIAN`)
* **Генерація PDF:** ReportLab
* **Обробка зображень:** Pillow (PIL)
* **Збірка дистрибутиву:** PyInstaller

## 💻 Встановлення та запуск із сирцевого коду

### 1. Клонування репозиторію
```bash
git clone [https://github.com/your-username/ZeoGrace.git](https://github.com/your-username/ZeoGrace.git)
cd ZeoGrace
```

### 2. Створення та активація віртуального середовища
**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows (CMD / PowerShell):**
```cmd
python -m venv venv
venv\Scripts\activate
```

### 3. Встановлення залежностей
```bash
pip install -r requirements.txt
```

*(Якщо файл `requirements.txt` відсутній, встановіть основні пакети: `pip install PyQt6 reportlab Pillow`)*

### 4. Запуск програми
```bash
python app.py
```

## 📦 Збірка виконуваного файлу (.exe / binary)

Для збірки автономного виконуваного файлу використовується **PyInstaller**. Обов'язково потрібно включити файл-шаблон порожньої бази даних `_blank.db`.

### Збірка для Windows:
```cmd
pyinstaller --noconsole --onefile --add-data "_blank.db;." app.py
```

### Збірка для Linux / macOS:
```bash
pyinstaller --noconsole --onefile --add-data "_blank.db:." app.py
```

Готовий файл буде створено у папці `dist/`.

## 📁 Структура проєкту

```text
ZeoGrace/
├── app.py               # Головна точка входу, інтерфейс QMainWindow, таблиці та меню
├── database.py          # Логіка БД SQLite, DDL, пошук шлюбів, дітей та автобэкапи
├── dialogs.py           # Діалогові вікна (редагування особи, фільтри, підтвердження, налаштування)
├── pdf_generator.py     # Генерація PDF-документів за допомогою ReportLab
├── pdf_components.py    # Кастомний канвас з нумерацією, віджет прев'ю та стилі експорту
├── config.py            # Конфігурація колонок, палітри кольорів PDF, константи
├── utils.py             # Сортування українською мовою, реєстрація шрифтів, форматування телефонів
├── demo_base.db         # Демонстраційна база (Особи несправжні - згенеровані ШІ)
└── _blank.db            # Шаблон порожньої бази даних для створення нових файлів
```
